BINKSFILMS — Gérer les films

Comment ça marche

  1. Tu modifies ce que tu veux ci-dessous : ajouter, archiver, supprimer, changer une bannière, une description…
  2. Tu cliques sur Télécharger films.js. Le fichier arrive dans tes téléchargements.
  3. Sur GitHub, page de ton dépôt → Add file → Upload files → tu glisses le nouveau films.js → Commit changes.
  4. Vercel remet le site à jour tout seul en ~30 secondes. Même adresse.
