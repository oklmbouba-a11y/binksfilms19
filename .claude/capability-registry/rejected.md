# Rejected Capabilities

Record reviewed capabilities we should not repeatedly reconsider unless circumstances materially change.

For each entry record:
- source;
- review date;
- reason for rejection;
- what would need to change for reconsideration.

Common rejection reasons:
- generic design recipes;
- stale version assumptions;
- unnecessary React/Next.js bias;
- large overlap with existing skills;
- excessive permissions/dependencies;
- weak maintenance or unclear provenance.
