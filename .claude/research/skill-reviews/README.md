# Skill Reviews

Capability Scout writes durable audits here when an external skill/plugin/MCP requires deeper evaluation.

Suggested filename: `YYYY-MM-DD-capability-name.md`.

Minimum review fields:
- source / maintainer;
- license;
- recency;
- versions;
- permissions/tools;
- dependencies;
- overlap;
- useful knowledge;
- risks / bias;
- decision: USE / ADAPT / BUILD / REJECT.
